### ALGO-000024: L versus NL
- **Subfield:** Structural complexity
- **Open:** Determine whether directed graph reachability can be decided deterministically using \(O(\log n)\) workspace.
- **Status:** Open since the 1960s–1970s. Savitch gives deterministic \(O(\log^2 n)\) space; Reingold solved undirected connectivity in logarithmic space, not directed reachability.
- **Type:** theory
- **Why:** Would identify the value of nondeterminism under severe memory constraints.
- **Key works:** Savitch (1970), *Relationships between Nondeterministic and Deterministic Tape Complexities*, DOI: 10.1016/S0022-0000(70)80006-X; Reingold (2008), *Undirected Connectivity in Log-Space*, DOI: 10.1145/1391289.1391291.
- **Related:** Formal verification—small-memory reachability certification; communication networks—memory-limited routing.
